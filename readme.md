# Reality Check
Currently in development.

A Chrome extension that analyzes web pages and provides quick credibility indicators.

## Features

- Detects source citations
- Checks for author attribution
- Checks for publication dates
- Counts AI-related terms
- Highlights potentially uncited claims
- Generates a simple credibility score

## Current Status

Prototype / MVP

The extension currently analyzes:

- Number of sources
- Author information
- Publication dates
- AI indicators
- Uncited paragraphs

## Future Plans
